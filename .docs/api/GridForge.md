# GridForge Unity API

The Unity companion extends GridForge through these adapter namespaces:

- [GridForge.Blockers](xref:GridForge.Blockers)
- [GridForge.Configuration](xref:GridForge.Configuration)
- [GridForge.Unity](xref:GridForge.Unity)
- [GridForge.Utility](xref:GridForge.Utility)

See the [GridForge core API](https://mrdav30.github.io/GridForge/) for the
engine-agnostic grid, topology, spatial, and diagnostics APIs.
