# GridForge Unity API

The Unity companion adds scene ownership, authoring data, blockers, diagnostic
gizmos, trace visualization, and logging adapters around GridForge.

Explore the adapter namespaces:

- [GridForge.Blockers](xref:GridForge.Blockers)
- [GridForge.Configuration](xref:GridForge.Configuration)
- [GridForge.Unity](xref:GridForge.Unity)
- [GridForge.Utility](xref:GridForge.Utility)

For engine-agnostic world, grid, voxel, topology, storage, tracing, occupant,
partition, and diagnostic contracts, browse the
[GridForge core API](https://mrdav30.github.io/GridForge/).
