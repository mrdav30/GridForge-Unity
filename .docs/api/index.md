# GridForge Unity API

GridForge-Unity provides Unity authoring, scene, diagnostics, and logging
adapters for the deterministic, engine-agnostic
[GridForge](https://github.com/mrdav30/GridForge) core library.

- [Unity user guide](xref:GridForge.Unity.UserGuide)
- [API reference](xref:GridForge.Unity)

Install one Unity package variant only:

- `com.mrdav30.gridforge` for the standard dependency chain.
- `com.mrdav30.gridforge.lean` for the same Unity integration without
  MemoryPack.
